## 1. 产品概述

实时多人涂鸦对战平台（Doodle Battle），支持2-8人同时在线的限时猜词绘画游戏。涂鸦者根据系统出题绘画，其他玩家实时观看并猜词，结合投票评选和回放功能，打造趣味社交竞技体验。

- 目标用户：喜欢休闲社交游戏的人群，朋友聚会、团队破冰、在线社交场景
- 核心价值：将经典"你画我猜"游戏数字化，增加竞技性和社交互动，提供流畅的实时多人对战体验

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 玩家 | 用户名注册/游客快速体验 | 创建/加入房间、参与游戏、投票、查看排行榜 |
| 房主 | 自动晋升（创建房间者） | 额外拥有开始游戏、踢人、设置回合数权限 |

### 2.2 功能模块
1. **登录页**：用户名注册、游客登录、记住登录状态
2. **大厅页**：房间列表、创建房间、快速匹配、在线人数
3. **房间等待页**：玩家列表、聊天、房主操作、游戏设置
4. **游戏页**：涂鸦画板、猜词输入、计时器、分数面板、聊天区
5. **投票页**：投票选择最佳涂鸦、投票结果展示
6. **结算页**：最终排名、个人成绩、回放入口
7. **回放页**：绘画过程回放、进度控制

## 3. 核心流程

### 3.1 游戏主流程
玩家登录 → 进入大厅 → 创建/加入房间 → 等待玩家 → 房主开始游戏 → 系统出题给涂鸦者 → 涂鸦者绘画（60秒） → 其他玩家猜词 → 猜对加分 → 时间到/所有人猜对 → 下一轮（换涂鸦者） → 所有轮次结束 → 投票最佳涂鸦 → 最终结算 → 可选回放

```mermaid
flowchart TD
    "A[玩家登录]" --> "B[进入大厅]"
    "B" --> "C{创建房间?}"
    "C" --> "|是| D[创建房间]"
    "C" --> "|否| E[加入/匹配房间]"
    "D" --> "F[房间等待页]"
    "E" --> "F"
    "F" --> "G[房主开始游戏]"
    "G" --> "H[系统随机出题]"
    "H" --> "I[涂鸦者绘画60秒]"
    "I" --> "J[其他玩家猜词]"
    "J" --> "K{猜对或时间到?}"
    "K" --> "|猜对| L[加分]"
    "K" --> "|时间到| M[轮次结束"]
    "L" --> "M"
    "M" --> "N{还有下一轮?}"
    "N" --> "|是| H"
    "N" --> "|否| O[投票最佳涂鸦]"
    "O" --> "P[最终结算]"
    "P" --> "Q{查看回放?}"
    "Q" --> "|是| R[回放页]"
    "Q" --> "|否| B"
```

### 3.2 回合内流程
每轮开始 → 显示题目给涂鸦者 → 3秒倒计时 → 开始绘画 → 其他玩家实时观看画布 → 玩家输入猜测 → 系统判断对错 → 正确：加分并提示其他玩家"有人猜对了" → 错误：显示错误提示 → 时间到或所有人猜对 → 显示正确答案 → 短暂休息 → 下一轮

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：活力橙 (#FF6B35) + 深邃靛蓝 (#1A1A2E)，打造游戏感与竞技感
- **辅助色**：明黄 (#FFD93D)、薄荷绿 (#6BCB77)、柔和粉 (#FF6B8A)
- **背景**：深色主题为主，搭配几何图案和渐变效果，营造电竞氛围
- **按钮风格**：圆角按钮，3D凸起效果，hover时微微上浮+阴影加深
- **字体**：标题使用粗体趣味字体，正文使用清晰易读的无衬线体
- **布局**：卡片式布局，游戏页面为沉浸式全屏
- **图标/表情**：使用lucide图标，配合游戏化视觉元素（星星、奖杯、画笔）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|

### 4.3 响应式设计
- 桌面优先设计，游戏页面最佳体验在1280px以上
- 1024px以下：猜词区移至画布下方
- 768px以下：工具栏简化为可展开面板

## 4.4 动效设计
- 页面切换：淡入淡出 + 轻微缩放
- 猜对动画：绿色对勾弹出 + 分数飞入动画
- 时间紧迫：最后10秒倒计时数字放大跳动
- 投票结果：柱状图动画增长
- 回合切换：画布擦除动画（从左到右扫过）
